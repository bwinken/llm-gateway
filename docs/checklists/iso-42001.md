# ISO/IEC 42001:2023 盤點清單

範圍：這個 gateway 在公司的 AI 管理系統裡扮演的角色。它不訓練也不微調模型，是「使用並轉供」第三方與開源模型的系統。所以和資料、模型開發有關的控制大多不適用，重點在運作監控、使用管理、對使用者的資訊、供應商。

標記說明見 [README](README.md)。條文 4 ~ 10（AI 政策、風險評鑑、影響評估流程、內稽、管理審查）全部是 🏢。編號與名稱是依記憶整理的中文摘要，引用前請對照標準原文。

## 對這個 gateway 最要緊的五項

1. **A.5 影響評估**：完全沒有，而且是 42001 和 27001 最大的差別。→ AUD-4
2. **A.6.2.4 / A.6.2.5 模型上架**：新模型現在改個設定就上線，沒有評估與核准紀錄。→ AUD-5
3. **A.10.3 供應商**：送到 Azure / AWS 的資料會被保存多久、會不會被用於訓練，要有書面答案。→ AUD-4
4. **A.3.3 / A.8.3 通報管道**。→ CMP-11
5. **A.8.2 使用者資訊**：使用者選模型時看不到「這個模型的資料會不會離開公司」。→ AUD-4 之後補上 dashboard
