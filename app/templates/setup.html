{# ── Troubleshooting (cert) ── #}
Troubleshooting
Still seeing certificate warning after install?

Fully close all browser windows (not just the tab) and reopen. Edge and Chrome cache the cert store on startup.

Office add-in still fails?

Restart the Office app (Excel, Word, PowerPoint). WebView2 reads the cert store on Office launch.

Need help?

Contact your IT administrator or the gateway operator.

{# Step 3 — Settings reference #}
3

Settings reference

The installer writes the minimum required keys. You can add any of the keys below to ~/.claude/settings.json to customise Claude Code's behaviour. model is a top-level key; everything else lives under env. 

// ~/.claude/settings.json
{
  "model": "your-model-alias",
  "env": {
    "ANTHROPIC_BASE_URL": "https://your-gateway",
    "ANTHROPIC_API_KEY":  "YOUR_API_KEY",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  }
}

{# ── Troubleshooting (Claude Code) ── #}
Troubleshooting
claude not found after install?

Close and reopen your terminal so the updated PATH takes effect.

TLS / certificate errors on first request?

If your gateway uses a private CA that Node.js can't see, set NODE_TLS_REJECT_UNAUTHORIZED to "0" in env. Or install the corporate CA via the tab for a proper fix.

Stuck on login / auth loop?

Run claude /doctor for diagnostics.
