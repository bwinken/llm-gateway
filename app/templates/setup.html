{# Step 2 #}
2

Run the installer

Administrator privileges are not required. The certificate is installed for your user only.

Option A — PowerShell (recommended)
  1. Right-click install-cert-user.ps1
  2. Select Run with PowerShell
  3. If prompted about execution policy, type Y and press Enter
Option B — Batch file
  1. Double-click install-cert.bat
  2. Wait for "CertUtil: -addstore command completed successfully"

{# ── Troubleshooting ── #}
Troubleshooting
PowerShell blocked by execution policy?

Open PowerShell and run: Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Still seeing certificate warning after install?

Fully close all browser windows (not just the tab) and reopen. Edge and Chrome cache the cert store on startup.

Office add-in still fails?

Restart the Office app (Excel, Word, PowerPoint). WebView2 reads the cert store on Office launch.

Need help?

Contact your IT administrator or the gateway operator.
