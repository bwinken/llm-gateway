🔌 API Integration Guide

Chat Completions POST /v1/chat/completions

OpenAI-compatible endpoint for generating chat responses.

from openai import OpenAI

client = OpenAI(
    base_url="http://{{ request.url.hostname }}:{{ request.url.port }}/v1",
    api_key="{{ user.api_key }}"
)

resp = client.chat.completions.create(
    model="radllm",
    messages=[
        {"role": "user", "content": "Hello!"}
    ]
)
Embeddings POST /v1/embeddings

Generate vector embeddings for text inputs.

from openai import OpenAI

client = OpenAI(
    base_url="http://{{ request.url.hostname }}:{{ request.url.port }}/v1",
    api_key="{{ user.api_key }}"
)

resp = client.embeddings.create(
    model="bge-m3",
    input=["The quick brown fox"]
)
Rerank POST /v1/rerank

Re-order a list of documents based on relevance to a query.

import requests

resp = requests.post(
    "http://{{ request.url.hostname }}:{{ request.url.port }}/v1/rerank",
    headers={
        "Authorization": "Bearer {{ user.api_key }}"
    },
    json={
        "model": "bge-reranker-v2-m3",
        "query": "What is deep learning?",
        "documents": ["Doc A content...", "Doc B content..."],
        "top_n": 3
    }
)
print(resp.json())
Score POST /v1/score

Get a relevance score for query-document pairs.

import requests

resp = requests.post(
    "http://{{ request.url.hostname }}:{{ request.url.port }}/v1/score",
    headers={
        "Authorization": "Bearer {{ user.api_key }}"
    },
    json={
        "model": "bge-reranker-v2-m3",
        "text_1": ["Apple"],
        "text_2": ["A fruit", "A tech company"]
    }
)
print(resp.json())
